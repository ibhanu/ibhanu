I am a **Senior Mobile Engineer & Tech Lead** with a track record of architecting and shipping mission-critical cross-platform applications and deep mobile OS integrations.

- 🚀 **Production Impact:** Scaled consumer & creator applications to **900K+ cumulative users** and **$25M+ in platform transactions** across [BigBang.Social](https://bigbang.social) and [Under25](https://under25.club).
- ⚡ **Engineering Rigor:** Cut production crash rates by **65% (down to 0.7%)**, resolved low-level memory leaks, and eliminated UI jank to ensure buttery-smooth **60 FPS** rendering.
- 📱 **Deep Native OS Surface:** Engineered custom Platform Channels bridging iOS (Swift/Objective-C) and Android (Kotlin/Java) for real-time media processing, camera pipelines, and automated KYC integrations.
- 🛠️ **DevOps & Team Velocity:** Built reusable design systems with 30+ core components, mentored engineering teams in TDD & clean architecture, and cut deployment cycles by **75%** via Fastlane and GitHub Actions CI/CD.
